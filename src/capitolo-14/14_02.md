# Analisi tecnica con l'AI

### Principio: Python calcola, l'AI interpreta

Incollare centinaia di candele in una chat è inefficiente e fa sbagliare i calcoli. Il metodo migliore è **calcolare gli indicatori con il codice** (Capitolo 5) e passare all'AI un **riassunto numerico compatto**, su cui chiederle di ragionare.

### Che cosa chiedere

- la **struttura** corrente (trend, range, transizione);
- i **livelli** rilevanti vicini al prezzo;
- due **scenari opposti**, con le condizioni che li attiverebbero;
- che cosa **invaliderebbe** ciascuno scenario;
- le **informazioni mancanti**.

### Che cosa non chiedere

- «dove andrà il prezzo?»: invita a una previsione che nessuno può dare;
- «devo comprare?»: la decisione dipende dal tuo piano e dal tuo rischio.

### Laboratorio: un riassunto numerico per l'AI

Si assume un DataFrame `df` con le colonne `high`, `low`, `close` e gli indicatori calcolati come nel Capitolo 5 (`ema50`, `ema200`, `rsi`, `atr`).

```python
import json


def snapshot(df):
    """Riassunto numerico per l'AI."""
    last = df.iloc[-1]
    hi = df["high"].iloc[-20:].max()
    lo = df["low"].iloc[-20:].min()
    data = {
        "close": round(last["close"], 2),
        "ema50": round(last["ema50"], 2),
        "ema200": round(last["ema200"], 2),
        "rsi": round(last["rsi"], 1),
        "atr": round(last["atr"], 2),
        "hh20": round(hi, 2),
        "ll20": round(lo, 2),
    }
    return json.dumps(data)
```

Il risultato è una riga di JSON da incollare nel prompt, dentro i tag `<dati>`. Sono poche cifre, ma sufficienti per ragionare su trend, momento, volatilità e distanza dai livelli.

### Template: analisi tecnica a scenari

```text
Agisci come analista tecnico
prudente.

<contesto>
Strumento: [..] Timeframe: [..]
Data: [oggi]. Swing trader.
</contesto>

<dati>
[incolla l'output di snapshot]
</dati>

Compiti:
1. Descrivi la struttura attuale
   in 3 righe.
2. Due scenari (rialzista e
   ribassista) con condizioni.
3. Cosa invaliderebbe ciascuno,
   con livelli numerici.
4. Cosa non puoi dedurre da
   questi dati.

Usa solo i dati forniti. Non dare
ordini di acquisto o vendita.
```
