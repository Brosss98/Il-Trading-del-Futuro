# Laboratorio pratico: sorprese e finestre di sicurezza in Python

Due funzioni semplici.

```python
import pandas as pd


def surprise(actual, forecast, sd):
    """Sorpresa standardizzata."""
    return (actual - forecast) / sd


def in_blackout(ts, events, mins=15):
    """True se ts è vicino a un evento."""
    d = pd.Timedelta(minutes=mins)
    return any(abs(ts - e) <= d
               for e in events)


print(round(surprise(165, 65, 75), 2))

events = pd.to_datetime([
    "2026-11-10 14:30",
    "2026-12-09 20:00",
])
t = pd.Timestamp("2026-11-10 14:20")
print(in_blackout(t, events))
```

Con questi valori, lo script dovrebbe stampare `1.33` e `True`.

Come usarlo:
- `surprise` lavora in migliaia di occupati (165 contro 65) con una deviazione standard ipotetica di 75. Per usarla davvero serve la serie storica reale delle sorprese.
- `in_blackout` segnala se un'ora è vicina a un evento. Nel Modulo 6 la useremo in un Expert Advisor per **bloccare nuovi ingressi** intorno alle notizie.
- Gli orari degli esempi sono in ora italiana: CPI alle 14:30 e decisione della Fed alle 20:00. Attenzione agli sfasamenti dell'ora legale tra USA ed Europa.
