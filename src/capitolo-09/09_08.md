# Laboratorio pratico: segnale e metriche in Python

Due funzioni. Si assume un DataFrame `df` con colonne `high` e `close`.

```python
import numpy as np


def trend_signal(df, fast=50, slow=200,
                 brk=20):
    """1 = long consentito, 0 = fuori."""
    c = df["close"]
    f = c.ewm(span=fast,
              adjust=False).mean()
    s = c.ewm(span=slow,
              adjust=False).mean()
    hh = df["high"].rolling(brk).max()
    up = (f > s) & (c > f)
    brk_up = c > hh.shift(1)
    return (up & brk_up).astype(int)


def stats(r):
    """Metriche da risultati in R."""
    r = np.asarray(r, dtype=float)
    wins = r[r > 0]
    loss = r[r < 0]
    if loss.size:
        pf = wins.sum() / abs(loss.sum())
    else:
        pf = float("inf")
    eq = np.cumsum(r)
    peak = np.maximum.accumulate(eq)
    dd = (peak - eq).max()
    return {
        "n": len(r),
        "win_rate": float((r > 0).mean()),
        "expectancy": float(r.mean()),
        "profit_factor": float(pf),
        "max_dd_R": float(dd),
    }


r = [2.5, -1, -1, 2, -1,
     -1, 3, -1, 1.5, -1]
print(stats(r))
```

Con i dieci risultati dell'esempio, `stats` dovrebbe restituire: 10 operazioni, win rate 0,4, expectancy 0,3, profit factor 1,5, max drawdown 2,0R.

**Note d'uso:**
- `trend_signal` confronta la chiusura con il massimo **precedente** (`shift(1)`), quindi non usa informazioni future. Il segnale nasce alla chiusura della candela: nel backtest va eseguito sulla candela **successiva**.
- `stats` restituisce un profit factor infinito se non ci sono perdite e converte i risultati in numeri semplici (float), per una stampa leggibile.
- Questi blocchi diventeranno il nucleo del motore di backtest dei Capitoli 15 e 16.
