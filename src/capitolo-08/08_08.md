# Laboratorio pratico: correlazioni e rischio in Python

Con `pandas` puoi calcolare tutto in poche righe. Si assume un DataFrame `prices` con una colonna per strumento (ad esempio EURUSD, GBPUSD, XAUUSD, US10Y) e date allineate.

```python
import numpy as np
import pandas as pd


def returns(prices):
    """Rendimenti logaritmici."""
    return np.log(prices).diff().dropna()


def corr_matrix(prices):
    """Matrice di correlazione."""
    return returns(prices).corr()


def rolling_corr(a, b, n=60):
    """Correlazione mobile su n giorni."""
    ra, rb = returns(a), returns(b)
    return ra.rolling(n).corr(rb)


def combined_risk(r1, r2, rho):
    """Rischio % di due posizioni."""
    return np.sqrt(r1**2 + r2**2
                   + 2 * rho * r1 * r2)


print(round(combined_risk(1, 1, 0.8), 2))
```

L'ultima riga stampa `1.9`, coerente con l'esempio della sezione 8.5.

**Come usarlo:**
- `corr_matrix(prices)` mostra in una tabella tutte le correlazioni a coppie. Cerca i valori sopra 0,7 o sotto -0,7.
- `rolling_corr(prices["XAUUSD"], prices["US10Y"])` restituisce una serie: tracciandola, vedrai quanto cambia la relazione nel tempo. Se oscilla tra -0,6 e +0,3, hai appena visto perché non va considerata fissa.
- In `combined_risk`, per una posizione long e una short, passa `-rho` al posto di `rho`.
- Controlla che le date siano allineate prima di calcolare: serie con giorni mancanti diversi producono correlazioni errate.
