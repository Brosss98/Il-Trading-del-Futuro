# Laboratorio pratico: analizzare il proprio diario con Python

Se tieni il diario in un foglio di calcolo, puoi misurare l'effetto della disciplina.

```python
import numpy as np
import pandas as pd


def by_plan(df):
    """Expectancy: piano seguito o no."""
    g = df.groupby("followed_plan")["r"]
    return g.agg(["count", "mean"])


def max_losing_streak(r):
    """Serie massima di perdite."""
    best = cur = 0
    for x in r:
        cur = cur + 1 if x < 0 else 0
        best = max(best, cur)
    return best


def exp_streak(n, win_rate):
    """Serie perdente attesa (stima)."""
    q = 1 - win_rate
    return np.log(n * win_rate) / np.log(1 / q)


df = pd.DataFrame({
    "r": [1.5, -1, -1, 2,
          -1.8, -1, 2.5, -1],
    "followed_plan": [True, True, True,
                      True, False, False,
                      True, True],
})
print(by_plan(df))
print(max_losing_streak(df["r"]))
print(round(exp_streak(200, 0.45), 1))
```

Con i dati dell'esempio, lo script dovrebbe mostrare: operazioni con piano seguito, 6 con media **+0,5R**; operazioni fuori piano, 2 con media **−1,4R**; una serie massima di perdite pari a 2; e una serie attesa di 7,5 su 200 operazioni.

**Come leggerlo:**
- `by_plan` risponde alla domanda più utile: *quanto mi costa non seguire il piano?* Nell'esempio le operazioni fuori piano sono quelle che perdono. Su un campione vero, è un'evidenza molto concreta.
- `max_losing_streak` ti dice quanto è stata lunga la serie peggiore, da confrontare con `exp_streak`.
- I dati dell'esempio sono troppo pochi per concludere qualcosa: servono molte operazioni.
