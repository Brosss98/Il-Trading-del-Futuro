# Le metriche che contano

Poche metriche, misurate con costanza.

### Di processo (le controlli tu)

- **Adesione al piano**: percentuale di operazioni fatte secondo le regole. Obiettivo: oltre il 90%.
- **Rispetto dei limiti**: giorni in cui hai superato la perdita massima o il numero di ordini.
- **Completezza del diario**: operazioni documentate.

### Di performance (dipendono anche dal caso)

- **Expectancy** in R e **profit factor**.
- **Max drawdown** in R e in percentuale.
- **Costi in R**: quanto del risultato lordo è assorbito da spread e commissioni.
- Risultato **per setup** e per condizione di mercato.

### Come leggerle

- Il **processo** si valuta ogni settimana. La **performance** solo su campioni ampi (almeno 100 operazioni).
- Ricorda l'errore standard (Capitolo 16): con pochi dati, un risultato può essere indistinguibile dal caso.
- Giudica la decisione con la matrice del Capitolo 11 (processo e esito), non dal solo saldo.

### Laboratorio: il report mensile in Python

Si assume un registro con le colonne `date`, `setup`, `r` e `followed`.

```python
import pandas as pd


def monthly_report(df):
    """Report mensile dal diario."""
    df = df.copy()
    d = pd.to_datetime(df["date"])
    df["month"] = d.dt.to_period("M")
    g = df.groupby("month")
    out = g["r"].agg(
        ["count", "sum", "mean"])
    out["adherence"] = g["followed"].mean()
    return out.round(2)


def by_setup(df):
    """Risultati per setup."""
    g = df.groupby("setup")["r"]
    return g.agg(
        ["count", "mean", "sum"]).round(2)


def max_dd_r(r):
    """Drawdown massimo in R."""
    eq = pd.Series(r).cumsum()
    return (eq.cummax() - eq).max()


df = pd.DataFrame({
    "date": ["2026-01-05", "2026-01-12",
             "2026-02-03", "2026-02-10",
             "2026-02-17"],
    "setup": ["pb", "pb", "brk",
              "pb", "brk"],
    "r": [1.5, -1, 2.0, -1, -1],
    "followed": [True, True, True,
                 False, True],
})
print(monthly_report(df))
print(by_setup(df))
print(max_dd_r(df["r"]))
```

Con i dati dell'esempio dovresti ottenere:
- **gennaio**: 2 operazioni, +0,5R in totale, adesione 100%;
- **febbraio**: 3 operazioni, 0R in totale, adesione 67%;
- per setup, `brk` con media +0,5R e `pb` con media −0,17R;
- drawdown massimo di **2R**.

Il valore sta nell'abitudine di guardare questi numeri ogni mese, sempre con la cautela dovuta ai campioni piccoli.
