# Laboratorio pratico: struttura e FVG in Python

Trasformiamo le definizioni in codice, **senza lookahead**. Si assume un DataFrame `df` con colonne `high` e `low`.

```python
import pandas as pd


def swings(df, k=3):
    """Swing confermati dopo k candele."""
    hi, lo = df["high"], df["low"]
    w = 2 * k + 1
    is_hi = hi == hi.rolling(
        w, center=True).max()
    is_lo = lo == lo.rolling(
        w, center=True).min()
    return (is_hi.shift(k, fill_value=False),
            is_lo.shift(k, fill_value=False))


def fvg(df):
    """Fair value gap a tre candele."""
    h2 = df["high"].shift(2)
    l2 = df["low"].shift(2)
    bull = df["low"] > h2
    bear = df["high"] < l2
    return bull, bear


def trend_label(his, los):
    """Trend dagli ultimi due swing."""
    up = his[-1] > his[-2]
    up = up and los[-1] > los[-2]
    dn = his[-1] < his[-2]
    dn = dn and los[-1] < los[-2]
    if up:
        return "rialzista"
    if dn:
        return "ribassista"
    return "misto"
```

**Come leggere il codice:**
- In `swings`, la finestra è centrata, ma il risultato viene **spostato in avanti di k candele** con `shift(k)`. Così il segnale appare solo quando, nella realtà, lo avresti potuto conoscere. Senza questo spostamento il backtest sfrutterebbe informazioni dal futuro.
- In `fvg`, la candela corrente (la terza) viene confrontata con quella di due posizioni prima. Usa solo dati già chiusi.
- `trend_label` riceve due liste di prezzi, per esempio gli ultimi swing high e swing low confermati. Con `his = [110, 115]` e `los = [100, 104]` restituisce `rialzista`.
