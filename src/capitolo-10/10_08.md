# Laboratorio pratico: dimensioni, Kelly e drawdown

```python
import numpy as np

rng = np.random.default_rng(1)


def lots(capital, risk_pct, stop_pips,
         pip_value=10.0, step=0.01):
    """Lotti per rischio fisso."""
    risk = capital * risk_pct
    raw = risk / (stop_pips * pip_value)
    n = np.floor(raw / step + 1e-9)
    return n * step


def shares(capital, risk_pct, entry, stop):
    """Quantità di azioni."""
    risk = capital * risk_pct
    return int(risk // abs(entry - stop))


def kelly(win_rate, payoff):
    """Frazione di Kelly."""
    return win_rate - (1 - win_rate) / payoff


def prob_dd(win_rate, rr, risk_pct,
            limit=0.30, n=500,
            sims=10_000):
    """P(drawdown >= limit) in n trade."""
    w = rng.random((sims, n)) < win_rate
    r = np.where(w, rr, -1.0)
    g = 1 + risk_pct * r
    eq = np.cumprod(g, axis=1)
    peak = np.maximum.accumulate(
        eq, axis=1)
    dd = 1 - eq / peak
    return (dd.max(axis=1) >= limit).mean()


print(round(lots(10_000, 0.01, 25), 2))
print(shares(10_000, 0.01, 50, 48))
print(round(kelly(0.45, 1.5), 3))
for rp in (0.01, 0.02, 0.05):
    p = prob_dd(0.45, 1.5, rp)
    print(rp, p)
```

Le prime tre stampe dovrebbero essere `0.4`, `50` e `0.083`, coerenti con gli esempi del capitolo. Le ultime tre dipendono dalla simulazione: eseguile e osserva come la probabilità di un drawdown del 30% cambia salendo da 1% a 5% di rischio.

**Note d'uso:**
- `lots` arrotonda **per difetto** al passo minimo. Il piccolo `1e-9` evita errori di arrotondamento in virgola mobile.
- `pip_value` va adattato alla coppia e alla valuta del conto.
- `kelly` può restituire valori negativi: significa che con quei numeri la strategia non ha vantaggio.
