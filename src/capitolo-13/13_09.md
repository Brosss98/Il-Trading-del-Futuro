# Laboratorio pratico: un costruttore di prompt in Python

Se usi spesso lo stesso modello di prompt, puoi automatizzarlo. Questa funzione assembla un prompt strutturato dai campi e un controllo segnala gli elementi mancanti.

```python
def build_prompt(role, context, task,
                 data, constraints,
                 fmt):
    """Assembla un prompt strutturato."""
    rules = "\n".join(
        f"- {c}" for c in constraints)
    parts = [
        f"Ruolo: {role}",
        f"<contesto>\n{context}\n</contesto>",
        f"<compito>\n{task}\n</compito>",
        f"<dati>\n{data}\n</dati>",
        f"Vincoli:\n{rules}",
        f"Formato: {fmt}",
    ]
    return "\n\n".join(parts)


REQUIRED = ["Ruolo:", "<compito>",
            "<dati>", "Formato:"]


def check(prompt):
    """Elementi mancanti."""
    return [k for k in REQUIRED
            if k not in prompt]


p = build_prompt(
    "analista macro prudente",
    "swing trader, rischio 0,5%",
    "elenca i rischi per EUR/USD",
    "[incolla i dati]",
    ["usa solo i dati forniti",
     "dichiara le assunzioni"],
    "cinque punti",
)
print(p)
print(check(p))
```

L'ultima riga dovrebbe stampare una lista vuota (`[]`), perché il prompt contiene tutti gli elementi richiesti.

**Come usarlo:**
- Puoi incollare il risultato di `print(p)` in qualunque chat con un assistente.
- Nel Capitolo 17 vedremo come inviare prompt come questo direttamente a un modello tramite API, dentro un programma.
- La funzione `check` è volutamente semplice. Estendila con i tuoi elementi obbligatori (per esempio il vincolo «non inventare»).
