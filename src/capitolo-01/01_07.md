# Laboratorio pratico: simulare la varianza con Python

Una strategia con expectancy positiva può comunque attraversare lunghe serie di perdite. Vediamolo con una simulazione Monte Carlo. Il codice è completo e funzionante (richiede Python 3.9+ e NumPy).

```python
import numpy as np

rng = np.random.default_rng(42)


def expectancy(win_rate, avg_win_r,
               avg_loss_r=1.0):
    """Expectancy in R per operazione."""
    return (win_rate * avg_win_r
            - (1 - win_rate) * avg_loss_r)


def simulate(win_rate, rr,
             risk_pct=0.01,
             n_trades=200,
             n_sims=10_000):
    """Simula n_sims percorsi di capitale.

    win_rate: probabilità di vincere
    rr: guadagno in R se si vince
    risk_pct: rischio per trade (0.01=1%)
    """
    wins = rng.random(
        (n_sims, n_trades)) < win_rate
    r = np.where(wins, rr, -1.0)
    growth = 1 + risk_pct * r
    equity = np.cumprod(growth, axis=1)
    peak = np.maximum.accumulate(
        equity, axis=1)
    dd = (equity / peak - 1).min(axis=1)
    return equity[:, -1], dd


if __name__ == "__main__":
    win_rate, rr = 0.45, 1.5
    e = expectancy(win_rate, rr)
    print(f"Expectancy: {e:+.3f} R")

    final, dd = simulate(win_rate, rr)
    med = np.median(final)
    p5 = np.percentile(final, 5)
    p95 = np.percentile(final, 95)
    loss = (final < 1).mean()
    worst = np.percentile(dd, 5)
    print(f"Mediano:      {med:.3f}")
    print(f"5° percentile:  {p5:.3f}")
    print(f"95° percentile: {p95:.3f}")
    print(f"P(perdita):   {loss:.1%}")
    print(f"DD mediano:   {np.median(dd):.1%}")
    print(f"DD peggiore 5%: {worst:.1%}")
```

**Come interpretare l'output.** Con questi parametri il vantaggio statistico esiste (+0,125R), ma vedrai che: a) una quota non trascurabile di percorsi chiude comunque in perdita su 200 operazioni; b) il drawdown massimo mediano è tipicamente a doppia cifra percentuale; c) nei casi sfavorevoli il drawdown è molto più profondo. **Ciò che sembra «sfortuna» è in realtà la distribuzione normale dei risultati.** Un trader che non l'ha mai visualizzata abbandona una buona strategia al primo drawdown fisiologico.
