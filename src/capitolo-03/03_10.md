# Laboratorio pratico: volatilità e valore del pip in Python

Due funzioni semplici.

```python
import numpy as np


def ann_vol(closes, periods=252):
    """Volatilità annualizzata."""
    r = np.diff(np.log(closes))
    return r.std(ddof=1) * np.sqrt(periods)


def pip_value(lots, pip_size=0.0001,
              contract=100_000):
    """Valore di 1 pip (valuta quotata)."""
    return lots * contract * pip_size


closes = np.array([100, 101, 99.5,
                   102, 103, 101.5])
print(f"Vol: {ann_vol(closes):.1%}")
print(f"Pip 0,5 lotti: {pip_value(0.5):.2f}")
```

Note d'uso:
- `periods` vale 252 per mercati con giorni di borsa (circa 252 all'anno) e 365 per le criptovalute, che non chiudono mai.
- La funzione `pip_value` restituisce 5,00 per 0,5 lotti su una coppia con quotazione in dollari, coerente con l'esempio del paragrafo 3.4. Per coppie con altre valute quotate serve una conversione.
- Sostituisci l'array `closes` con chiusure giornaliere reali (da file CSV o dalla piattaforma) e confronta la volatilità di strumenti diversi.
