# Il walk-forward

Un backtest singolo su tutto il periodo non dice se la strategia regge su dati nuovi. Il **walk-forward** simula l'uso reale: si ottimizzano i parametri su una finestra di *training* e si valutano, senza modificarli, sulla finestra successiva di *test*. Poi la finestra avanza e si ripete.

```python
import numpy as np


def score(d, g):
    k, rr = g
    r = backtest2(d, signals(d),
                  rr=rr, k=k)
    return np.mean(r) if r else -9.0


def walk_forward(df, train=1500,
                 test=500):
    """Ottimizza in train, valuta in test."""
    grid = [(k, rr)
            for k in (1.5, 2.0, 2.5)
            for rr in (1.5, 2.0, 3.0)]
    out, s = [], 0
    while s + train + test <= len(df):
        tr = df.iloc[s:s + train]
        te = df.iloc[s + train:
                     s + train + test]
        best = max(grid, key=lambda g:
                   score(tr, g))
        r = backtest2(te, signals(te),
                      rr=best[1], k=best[0])
        m = float(np.mean(r)) if r else 0.0
        out.append((best, len(r), m))
        s += test
    return out


for g, n, m in walk_forward(df):
    print(g, n, round(m, 3))
```

Gli indicatori (EMA, RSI, ATR) devono essere calcolati **prima** sul DataFrame completo: sono causali, cioè usano solo dati passati, quindi non introducono lookahead.

**Come leggere i risultati:**
- confronta l'expectancy in training con quella in test: se in test è sistematicamente **molto peggiore**, stai facendo overfitting;
- osserva se i parametri scelti cambiano molto da una finestra all'altra: se sì, non sono robusti;
- controlla quante operazioni ci sono in ogni finestra: con pochissime operazioni i numeri non significano nulla.

### Quanto è incerta una stima?

L'errore standard dell'expectancy è circa `deviazione standard dei risultati / √n`. Con deviazione standard di 1,2R:
- 100 operazioni → ±0,12R
- 150 operazioni → ±0,10R
- 400 operazioni → ±0,06R

E un intervallo di confidenza al 95% è circa il doppio. Un'expectancy di +0,08R misurata su 150 operazioni **non è distinguibile da zero**.
