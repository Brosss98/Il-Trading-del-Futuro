# Il backtest in Python: gap e costi realistici

Nel Capitolo 15 il motore di test ignorava i gap e usava un costo fisso in R. Entrambe le semplificazioni sono ottimistiche. Nota un fatto importante: **un costo fisso in prezzo equivale a un costo variabile in R**.

> costo in R = (spread + slippage) / rischio

Esempio: spread più slippage = 0,40. Se il rischio (2 ATR) vale 4,00, il costo è **0,10R**. Se la volatilità scende e il rischio vale 1,60, il costo sale a **0,25R**. Nei periodi di bassa volatilità i costi pesano molto di più sulla strategia.

```python
def backtest2(df, sig, rr=2.0, k=2.0,
              max_bars=40, spread=0.1,
              slip=0.05):
    """Come backtest, con gap e costi."""
    o = df["open"].to_numpy()
    h = df["high"].to_numpy()
    l = df["low"].to_numpy()
    c = df["close"].to_numpy()
    a = df["atr"].to_numpy()
    s = sig.to_numpy()
    res, i, n = [], 0, len(df)
    while i < n - 2:
        if not s[i]:
            i += 1
            continue
        e = o[i + 1]
        risk = k * a[i]
        stop = e - risk
        tp = e + rr * risk
        last = min(n, i + 1 + max_bars)
        out, j = None, i + 1
        while j < last:
            if j > i + 1 and o[j] <= stop:
                out = (o[j] - e) / risk
                break
            if l[j] <= stop:
                out = -1.0
                break
            if h[j] >= tp:
                out = rr
                break
            j += 1
        if out is None:
            j = last - 1
            out = (c[j] - e) / risk
        cost = (spread + slip) / risk
        res.append(out - cost)
        i = j + 1
    return res
```

**Novità rispetto al Capitolo 15:**
- se una candela **apre già sotto lo stop** (gap), l'uscita avviene all'apertura, con una perdita maggiore di 1R;
- il costo dipende dal rischio di ogni operazione;
- i gap favorevoli oltre il target vengono trattati in modo prudente (si prende il target);
- `spread` e `slip` sono in **unità di prezzo** dello strumento: adattali al tuo simbolo e al tuo broker.

Ripeti il test di sanità su dati casuali con `backtest2`: l'expectancy deve restare vicina a zero, meno i costi.
