# Lo Strategy Tester di MT5 e il confronto di parità

### Le modalità di simulazione

- **Ogni tick basato su tick reali**: la più realistica, se il broker fornisce la storia dei tick. Più lenta.
- **Ogni tick**: tick simulati a partire dalle barre da un minuto.
- **OHLC a 1 minuto**: veloce, approssimata.
- **Solo prezzi di apertura**: velocissima, adatta solo a logiche che operano sull'apertura della barra e senza stop intrabarra.

Per un EA con stop e target usa **tick reali** (o almeno «ogni tick») e imposta **spread, deposito e leva** realistici. Controlla la *qualità della modellazione* nel report. Lo strumento offre anche una finestra di *forward* per le ottimizzazioni: usala.

### La procedura di parità

1. Scarica gli stessi dati in Python (CSV esportato o libreria `MetaTrader5`).
2. Esegui il backtest in Python e lo Strategy Tester sullo stesso periodo.
3. Confronta **le date di ingresso** e i risultati operazione per operazione.
4. Indaga ogni divergenza: parametri diversi? orari? un indicatore calcolato in modo diverso? spread variabile?

```python
import MetaTrader5 as mt5
import pandas as pd

mt5.initialize()
r = mt5.copy_rates_from_pos(
    "XAUUSD", mt5.TIMEFRAME_H4, 0, 5000)
df = pd.DataFrame(r)
df["time"] = pd.to_datetime(
    df["time"], unit="s")
mt5.shutdown()
```

Questo codice funziona su Windows con il terminale MT5 installato e in esecuzione. Il simbolo dipende dal broker.

```python
def compare(py_times, mt_times):
    a, b = set(py_times), set(mt_times)
    return {
        "comuni": len(a & b),
        "solo_python": sorted(a - b),
        "solo_mt5": sorted(b - a),
    }
```

Se i due elenchi coincidono quasi del tutto, hai una buona prova che la logica sia stata tradotta bene. Differenze piccole sono normali (spread, slippage, tick). Differenze grandi indicano un bug.
