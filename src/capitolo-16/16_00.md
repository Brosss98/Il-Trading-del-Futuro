# Capitolo 16 - Programmazione e Automazione: Sviluppare Expert Advisor (MQL5) e Script in Python per l'Analisi e il Backtesting

*Il Trading del Futuro · Modulo 6: Automazione, coding e backtesting con l'AI*

**Obiettivi di apprendimento**

Al termine di questo capitolo sarai in grado di:
- distinguere i compiti di Python e di MQL5 e usarli insieme;
- scrivere la struttura di un Expert Advisor robusto, con rischio percentuale, filtro spread e logica a candela chiusa;
- migliorare il backtest in Python con gap, costi variabili e walk-forward;
- confrontare Python e Strategy Tester di MT5 per scovare i bug;
- capire come integrare un modello di machine learning tramite ONNX, senza lookahead;
- chiedere all'AI codice MQL5 e Python in modo controllabile;
- capire perché la maggior parte degli EA di prima generazione perde.
