# Laboratorio pratico: classificare le candele con Python

Questo esempio trasforma le regole di lettura in codice. È un filtro didattico, non una strategia: le soglie sono arbitrarie. Le candele sono tuple (open, high, low, close).

```python
def classify(o, h, l, c):
    rng = h - l
    if rng == 0:
        return "piatta"
    body = abs(c - o) / rng
    up = (h - max(o, c)) / rng
    low = (min(o, c) - l) / rng
    if low >= 0.6 and up <= 0.2:
        return "pin bar rialzista"
    if up >= 0.6 and low <= 0.2:
        return "pin bar ribassista"
    if body <= 0.1:
        return "doji"
    return "normale"


def bull_engulfing(prev, cur):
    po, pc = prev[0], prev[3]
    co, cc = cur[0], cur[3]
    return (pc < po and cc > co
            and co <= pc and cc >= po)


print(classify(100, 101, 96, 100.8))
print(classify(100, 102, 98, 100.2))
prev = (101, 101.5, 99.5, 100)
cur = (99.8, 102, 99.5, 101.5)
print(bull_engulfing(prev, cur))
```

Con i valori dell'esempio, lo script dovrebbe stampare: `pin bar rialzista`, `doji` e `True`.

**Che cosa osservare:**
- `classify` esprime ombre e corpo come **frazioni del range**, così la regola funziona su qualunque strumento e timeframe.
- Il pattern engulfing confronta solo i **corpi**, non le ombre.
