# Laboratorio pratico: gli indicatori in Python
Con `pandas` puoi calcolare tutti gli indicatori del capitolo. Si assume un DataFrame `df` con colonne `open`, `high`, `low`, `close`.

```python
import pandas as pd


def sma(s, n):
    return s.rolling(n).mean()


def ema(s, n):
    return s.ewm(span=n,
                 adjust=False).mean()


def rsi(close, n=14):
    d = close.diff()
    gain = d.clip(lower=0)
    loss = -d.clip(upper=0)
    a = 1 / n
    ag = gain.ewm(alpha=a,
                  adjust=False).mean()
    al = loss.ewm(alpha=a,
                  adjust=False).mean()
    rs = ag / al
    return 100 - 100 / (1 + rs)


def atr(df, n=14):
    pc = df["close"].shift(1)
    tr = pd.concat([
        df["high"] - df["low"],
        (df["high"] - pc).abs(),
        (df["low"] - pc).abs(),
    ], axis=1).max(axis=1)
    return tr.ewm(alpha=1 / n,
                  adjust=False).mean()


df["ema50"] = ema(df["close"], 50)
df["rsi"] = rsi(df["close"])
df["atr"] = atr(df)
```

**Note d'uso:**
- Il parametro `span=n` dell'EMA corrisponde a `k = 2/(n+1)` visto nella sezione 5.4.
- RSI e ATR usano la media di Wilder (`alpha = 1/n`). I valori possono differire leggermente dalla tua piattaforma nei primi periodi, perché cambia l'inizializzazione.
- Per lo stop basato sull'ATR: `stop = entry - 1.5 * df["atr"].iloc[-1]`.

### Attenzione al lookahead bias

Per individuare i massimi di oscillazione si può usare una finestra centrata:

```python
def swing_highs(high, k=3):
    w = 2 * k + 1
    mx = high.rolling(
        w, center=True).max()
    return high[high == mx]
```

Questo codice guarda `k` candele **nel futuro** rispetto al punto individuato. Va bene per studiare il grafico a posteriori, ma in un backtest **non puoi sapere** che un massimo è tale finché non sono passate `k` candele. Usarlo così com'è gonfia i risultati con informazioni che non avresti avuto. Torneremo sul tema nel Modulo 6.
